📱 Telegram — el canal principal

Telegram es la opción predeterminada por buenas razones: API estable y gratuita, soporte para archivos, botones inline, grupos y canales. 95% de los casos de uso de un asistente personal funcionan perfectamente en Telegram.

📡 Polling vs webhook

Polling (Recomendado para desarrollo)

El bot pregunta periódicamente a Telegram: "¿hay mensajes nuevos?". Simple, sin infraestructura. Latencia de 1-2 segundos.

Webhook (Para producción)

Telegram envía mensajes directamente a tu URL. Requiere HTTPS público. Sin latencia extra. Ideal para VPS.

💡 Seguridad en Telegram

Configura TELEGRAM_ALLOWED_USERS solo con tus IDs. Cualquier persona puede enviar mensajes a un bot de Telegram: sin una whitelist, cualquiera controla tu Jarvis.

🔗 BaseChannel — el contrato universal

O BaseChannel es la abstracción que permite que el Agent sea independiente del canal. No importa si usas Telegram o Discord: el Agent solo llama a send() y la implementación se encarga del resto.

🧩 Interfaz BaseChannel

class BaseChannel(ABC):

@abstractmethod
async def start(self) -> None:
"""Inicializa la conexión y empieza a escuchar mensajes"""

@abstractmethod
async def send(self, user_id: str, message: str) -> None:
"""Envía una respuesta al usuario"""

@abstractmethod
async def stop(self) -> None:
"""Cierra la conexión de forma ordenada"""

💬 Discord y Slack

Para equipos, Discord y Slack son los canales naturales. Un Jarvis dentro del workspace del equipo elimina la necesidad de salir de la plataforma para hacerle preguntas al asistente.

🎮 Discord

  • • discord.py con eventos on_message
  • • Slash commands para interacción estructurada
  • • Un thread por conversación para organizar
  • • Reactions para aprobación/rechazo

💼 Slack

  • • Bolt SDK con OAuth 2.0
  • • Events API para escuchar mensajes
  • • Manejador de menciones (@atlas)
  • • Block Kit para respuestas enriquecidas

📧 Canal de correo electrónico IMAP

El correo electrónico es el canal con mayor ROI para la automatización. Clasificación, categorización y respuesta automática a correos rutinarios ahorra horas a la semana sin exigir cambios de hábitos: Jarvis opera en tu bandeja de entrada actual.

🎤 Palabra de activación por voz

El canal de voz convierte a Jarvis en un asistente totalmente manos libres. Con Whisper para transcripción y una palabra de activación configurable, hablas con naturalidad y Jarvis responde con voz.

💡 Consejo sobre latencia

Para respuestas de voz en tiempo real, usa Whisper tiny (velocidad) para la transcripción y un modelo TTS local para la síntesis. Es posible lograr una latencia total inferior a 1 segundo con hardware de gama media.

🎙 Pipeline de voz

Micrófono → VAD (detecta el habla) → Buffer de audio
→ Verificación de Wake word ("¿Atlas"?)
→ Whisper STT → texto transcrito
→ Agent.process(texto)
→ TTS (text-to-speech)
→ Speaker (respuesta de voz)
