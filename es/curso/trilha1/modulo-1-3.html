🐍 Requisitos previos y Python

INTELECTO exige Python 3.11+ como mínimo absoluto. Las versiones anteriores no incluyen todas las funciones de async y tipado que usa el proyecto. Las dependencias son deliberadamente mínimas.

📦 requirements.txt minimalista

httpx>=0.27.0 # HTTP async client
python-telegram-bot # Canal de Telegram
cryptography # Fernet + PBKDF2
python-dotenv # .env loader
aiosqlite # SQLite async
# Nada más. Cero frameworks.

🔑 Cuenta de OpenRouter

O OpenRouter es la opción predeterminada para INTELECTO porque resuelve el problema del bloqueo por proveedor con elegancia quirúrgica: una clave de API da acceso a más de 100 modelos, y cambiar de modelo consiste solo en cambiar una cadena.

🎯 ¿Por qué OpenRouter?

  • •100+ modelos: GPT-4o, Claude 3.5, Mistral, Llama 3, Gemini — todos con una sola clave
  • •Facturación unificada: Una tarjeta, una factura, visibilidad del costo por modelo
  • •Fallback automático: Si un modelo falla, lo cambias en segundos
  • •Interfaz compatible con OpenAI: El mismo código funciona sin cambios
1

Crear una cuenta en openrouter.ai

2

Ir a Claves → Create API Key

3

Copiar la clave (comienza con sk-or-)

📝 Configuración de .env

El archivo .env es la única fuente de configuración sensible. Nunca pongas claves directamente en el código. setup carga el .env automáticamente y NUNCA debe ir al git.

📄 .env Ejemplo completo

# Proveedor principal
OPENROUTER_API_KEY=sk-or-v1-...
MODEL_NAME=anthropic/claude-3.5-sonnet

# Canal de Telegram
TELEGRAM_BOT_TOKEN=1234567890:AAF...
TELEGRAM_ALLOWED_USERS=123456789

# Configuración del agente
MAX_ROUNDS=5
WORKSPACE_DIR=./workspace
LOG_LEVEL=INFO

⚠ Regla crítica de seguridad

O .env debe estar en el .gitignore. Verifica siempre antes de hacer commit. Una clave de API expuesta en GitHub puede generar facturas de cientos de dólares en cuestión de horas; esto ocurre con frecuencia con los bots de escaneo automatizados.

🐳 Docker vs nativo

La elección entre Docker y nativo afecta tu flujo de trabajo. Para desarrollo, el nativo es más ágil. Para producción, Docker Compose garantiza la reproducibilidad y facilita el monitoreo.

🐍 Modo nativo

  • ✓Debug instantáneo con pdb/breakpoint
  • ✓Recarga automática con watchdog
  • ✓Acceso directo al filesystem
  • ✗Depende del entorno local
python main.py

🐳 Modo Docker

  • ✓Aislamiento total del entorno
  • ✓Deploy reproducible en cualquier servidor
  • ✓Reinicio automático con --restart unless-stopped
  • ✗Sobrecarga de compilación e inicio
docker compose up -d

💡 Lista de verificación de smoke test

  • ✓El bot funciona sin errores en la terminal
  • ✓El mensaje se recibió (aparece en el log)
  • ✓Se llamó al LLM (costo en OpenRouter)
  • ✓La respuesta llegó a Telegram
  • ✓audit.log contiene el registro de la interacción
